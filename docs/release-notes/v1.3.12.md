## New features

* **Claude Code and Codex's built-in `/goal` now keeps a work record.** Type `/goal <objective>` and
  How It Works opens a record for it, then closes it when the goal is met — the same record you would
  get from the `/astera-task` skill, without declaring the work twice. Claude closes it on its own;
  on Codex you mark the goal complete yourself.
* **A `/goal` that lands on work already open says so, and offers to close it.** The notice carries
  the same Complete button the record's own row has. The blocked `/goal` is no longer dropped: it
  retries itself the moment the way is clear, which matters on Claude, where `/goal` announces itself
  exactly once.
* **A finished record gets a short title of its own.** The write-up names the work in under 40
  characters, instead of the list showing the whole request back to you. Hovering still shows what
  you originally asked for.

## Fixes

* **The blocked-`/goal` notice closes the moment its button is pressed**, rather than waiting for the
  work it closes to finish.
* **The Korean `/goal` notice reads correctly** — product name casing, and a double passive.
