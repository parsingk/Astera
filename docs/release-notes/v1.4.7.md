## New features

* **Creative Hub in Settings.** The Higgsfield tab is now Creative Hub, the place for the outside creative
  platforms whose CLI accounts Astera keeps. Higgsfield is its first platform, and the messages that send
  you or an agent to that setting now say Settings > Creative Hub > Higgsfield.
* **Every Claude session knows what Astera offers.** When a Claude session starts, Astera tells it which of
  its features are turned on, and the app and browser skills now come into play whenever the agent needs
  them, not only when you ask for them by name.
* **The agent's app fits its mirror tab.** An app an agent runs on the hidden desktop is laid out at the size
  of the tab that mirrors it, and the picture fills that tab and follows it when you resize. A
  self-maximizing app used to show at a quarter of its size in the corner of a black frame.

## Fixes

* **Codex workers act as themselves.** Codex 0.160 runs a shared background server, and every Codex
  session's shell commands ran with the environment of whichever session had started that server. A Codex
  worker's `astera` calls could then go to another profile's Host, or arrive under another session's name;
  a worker asking a question was told the Host could not be reached. Astera now starts Codex sessions with
  `--no-daemon` when the installed Codex supports it, so each one's commands carry its own identity.
* **Bare video and image names become links.** When Claude Code sends a file from the agent's own folder
  with no path in front of it (`› [file] seg31.mp4`), the line now opens in the viewer like the others.
