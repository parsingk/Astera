## Fixes

* **The Host no longer eats a CPU core after the app restarts.** Astera's background Host keeps running
  when the app closes. Each app launch used to remove and recreate a folder the Host was watching, and on
  Windows a watch on a removed folder fires without pause: an idle Host could hold a full core for days.
  The app now empties that folder instead of removing it, and every folder watch in the Host and the app
  closes itself when its folder goes away.
* **Claude's notifications keep arriving after a relaunch.** The same folder carries Claude's hook
  events (finished turns, questions waiting, Slack). After a relaunch under a running Host it could be
  left missing, and those events were silently lost until the next launch.
* **Video and image links follow the agent into subfolders.** When an agent `cd`s into a subfolder,
  Claude Code prints the files it sends relative to that folder (`› [file] clips\a.mp4`). Those paths are
  now resolved against the agent's current folder first, so they open in the viewer like the others.
