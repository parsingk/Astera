## Fixes

* **Chat shows Claude's auto permission mode.** A session that starts in `auto` (your
  `permissions.defaultMode`) used to read 기본/Default while Claude acted without asking. The mode button
  now says Auto, and Auto is in its menu.
* **A resumed Claude chat names the right model before its first turn.** It used to show the settings'
  default until Claude answered, while it was already running the model the conversation was last on.
* **A failed Codex turn reads as a sentence, and stays in the conversation.** The error used to be the
  API's raw JSON, and a reopened conversation showed the question with nothing after it.
* **Codex 0.160 tool rows say what ran.** Codex now sends every tool through one script, so each row read
  "exec". Commands read as runs again, and MCP and goal calls show their own names.
* **History titles for Codex goals and slash commands.** A session started with `/goal` is titled by its
  objective instead of Codex's internal continuation note, and `/astera-task …` reads as typed instead of
  as raw tags.
* **Astera's own write-ups no longer appear in History.** The Claude runs that write How It Works
  explanations leave no session behind.
* **How It Works counts work done through Claude sub-agents.** Claude Code now calls its sub-agent tool
  `Agent`; edits made that way were not counted as the session's.
* **Rolling recognises Claude's Fable limit.** The message no longer carries the model number, so the
  limit went unnoticed and the session was not handed to another account.
