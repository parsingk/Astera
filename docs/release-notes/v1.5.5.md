## Fixes

* **No more trust question about the screenshot folder.** Every Claude session opened with Claude Code asking whether
  you trust Astera's `preview/shots` folder, where Design Mode and the agent browser save screenshots, and the answer
  lasted for that session only. Sessions no longer add that folder as a working directory. A rule in their settings
  lets them read it, and only read it, so screenshots still open without a permission question.
* **A worker's commit no longer fails on a locked git index.** When a worker started, Astera read its folder's git
  state in a way that can rewrite the index under `.git/index.lock`, so a commit the worker made at that moment could
  fail with "index.lock: File exists". The reads at a worker's start, at a Host restart and around an external review
  now leave the index alone.
* **Counts read right when there is one.** English and Spanish text said things like "1 sessions", and the
  conversation view showed "1 lines". Counts that can be one now read correctly, for example "1 line", "1 credit", and
  "The check passed" where "All 1 checks passed" appeared.
* **Japanese and Spanish are complete.** Each gained the 457 strings it was missing, so neither falls back to English
  any more. Spanish now addresses you as tú throughout, as most of it already did.
