## New features

* **A worktree's pull request is shown.** The worktree list carries the PR number and a glyph for its
  state — open, draft, merged, closed — and one more dot when the PR's checks are still running or
  have failed. Clicking it offers to open the PR in a browser or copy its link. Settings → GitHub
  shows whether your `gh` login is working and lets you turn the automatic refresh off.
* **You can create a pull request from a worktree.** A worktree holding commits its base does not
  have shows a pull request icon, and clicking it opens a dialog that pushes the branch and creates
  the pull request in one step.

## Fixes

* **A project's session list says it is loading** instead of showing "No sessions" until the list
  arrives.
* **Agent orchestration and work unit tracking now say they need a git repository.** Without one,
  work unit tracking would start a row and then drop it without a word.
