## Fixes

* **A resize handle lets go when you do.** Dragging the sidebar's edge, the line between split panes, the top of the
  bottom panel or the line in a Markdown file's split view could keep following the pointer after the mouse button was
  released, while an agent tab or an app tab was open beside it. Each of these handles now ends the drag on the first
  pointer move with no button held, and keeps the size it had at that point.
