## New features

* **How much of each account's limit is used is shown in the sidebar's account tab.** Two bars sit on
  each account — the 5-hour window on top, weekly underneath — in the sidebar panel and in
  Settings → Accounts. Clicking an account opens the detail: the usage rate, when the window resets,
  and when the reading was last updated. Codex accounts are not supported yet.
* **Desktop notifications.** Astera now sends an OS notification when a session is waiting on a
  choice or a permission approval, when it stops on a usage limit, and — off by default — when
  rolling moves it to another account. One is sent only while you are looking at another session or
  at another window, and clicking it brings Astera forward on that session's tab. The switches are
  in Settings → Notifications.
* **A session tab can be renamed.** Double-click the tab, or pick Rename from its context menu —
  Enter commits, Escape cancels, and clearing the name puts the folder name back. Two tabs on the
  same project are no longer indistinguishable, and neither are their notifications: the name is
  used wherever the session is named, including Slack message prefixes and desktop notification
  titles, and it survives a roll onto another account.

## Fixes

* **The selected run configuration is remembered per project.** Two npm projects each having a `dev`
  script was enough to lose the choice — pick one in project B, visit project A, come back, and B
  was showing A's selection.
