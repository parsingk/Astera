## New features

* **Watch an agent's videos and images inside Astera.** A file path a session prints, in a terminal or
  chat session or the bottom terminal, is now a link when the file exists (absolute, or relative to the
  session's folder). A video or image opens in a viewer tab that plays and seeks; other files open in
  the editor as before. The viewer has Open in default app and Show in folder, and the files an agent
  sends with SendUserFile in the conversation view open the same way.
* **The viewer keeps up with regenerated clips.** Switching to another tab pauses a video and keeps its
  place. When a clip is written again under the same name, the open viewer reloads once the write has
  finished and resumes where you were.

## Fixes

* **An agent learns about your other Higgsfield accounts before it gives up.** Checking the balance with
  `higgsfield account status` now also names the other accounts Astera keeps and their credits, so an
  agent asks you which one to use instead of asking you to top up. Astera's skill tells agents to check
  `astera higgsfield list` before stopping for credits.
* **An expired Higgsfield login points to the right place.** The agent is told to ask you to log in
  again in Settings > Higgsfield, not to run `hf auth login` (on many computers `hf` is Hugging Face's
  command), and the account reads "log in again".
* **Network paths in terminal output are left alone.** A `\\server\share\…` path printed in a session
  is never looked up, so hovering it cannot make Windows contact that server.
