## New features

* **Several Higgsfield accounts, one switch.** Settings > Higgsfield keeps more than one Higgsfield CLI
  account: import the login you already have (it is copied, not moved), add another and log in, and pick
  the one in use. Every `higgsfield` or `higgs` command an agent runs in an Astera session, terminal or
  chat, runs under that account, so switching is one click instead of swapping login files by hand.
* **The agent asks before it switches.** When the account in use cannot pay for a `generate create` or
  `generate workflow`, the job is not created; the agent is told how many credits each account has and
  asks you which one to use, then runs `astera higgsfield use --account <account>`. Astera never switches
  on its own. `astera higgsfield list` shows the accounts and their credits.
* **Assets cross accounts.** An upload or job id made under one account is handed to the other account as
  the file it stands for, so a reference image or a generated clip keeps working after a switch.
* **Logins are looked after.** The Higgsfield CLI deletes its login file when a token refresh fails;
  Astera keeps a backup and puts it back once. A job is never run twice after that, so it is never paid
  for twice. An expired login reads "log in again", a new login picks its workspace when there is only
  one, and a missing CLI program (for example one an antivirus quarantined) is named as such.
* **Logging in from Settings shows its progress.** While a login waits, the row offers the link to copy
  (open it in a private window when your default browser is signed in to the other account) and a
  Cancel button; the rest of the tab keeps working.

## Fixes

* **Detected accounts are registered once.** Confirming the first-run account detection could add every
  account twice. Importing a folder that is already registered now keeps the one account.
* **Chat agents get Astera's command line first.** Chat sessions now have the same `astera` command and
  session folder on their PATH as terminal sessions.
* **Hugging Face's `hf` is left alone.** Only the Higgsfield CLI is routed through an account; an `hf`
  that belongs to another program runs untouched.
