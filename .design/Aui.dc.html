assistant-ui 로 만든 대화 뷰

그림이 아니라 화면 캡처입니다. assistant-ui 의 Thread 를, 대화 기록을 흉내 낸 외부 스토어에 물려 띄우고 Astera 껍데기를 입혔습니다. 한 줄 작업 표시와 승인 대기 배너까지 실제로 눌러서 동작하는 상태입니다.

@assistant-ui/react 0.15.18 · shadcn 레지스트리 11개 파일
우리가 쓴 것: ToolFallback, ToolGroup, Banner 슬롯 셋
평소 · 작업 표시를 펴 둔 상태
답할 것이 있을 때 · 입력창이 잠긴다

한 줄 작업 표시

  • 기본은 Used tool: Read 였고, 지금은 읽음 store.ts 412줄 입니다.
  • 접힌 줄은 무엇을 몇 번 했는지 셉니다. 읽기 1 · 찾기 1, 수정 2 · 실행 1.
  • 통과는 초록, 실패는 빨강. 파일 트리의 git 색과 같은 값입니다.

답할 것이 있을 때

  • 배너는 선택지를 다시 그리지 않습니다. 기다리는 중이라고만 말하고 터미널로 보냅니다.
  • 기다리는 동안 입력창이 잠깁니다. 터미널에서 답해야 이어집니다.
  • 터미널 탭에 주황 점이 떠서, 대화를 보고 있어도 놓치지 않습니다. 터미널 자체는 지금 것 그대로입니다.

다크에서 고친 것과 남은 것

  • 입력창. --composer-bg 가 :root 에서 계산돼 다크 값을 못 받습니다. 색을 직접 지정하고 모서리를 24px 에서 8px 로. 보내기 버튼은 저쪽 것 그대로 두고 accent 색만 토큰으로.
  • 스크롤바. 앱 규칙 그대로. 10px, 손잡이 #23232a, 투명 트랙.
  • 남은 것: Tailwind 와 shadcn 이 함께 들어오고, 마크다운 렌더러가 둘이 됩니다. 입력창 잠금도 CSS 가 아니라 컴포저의 disabled 로 가야 합니다.
